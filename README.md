# Танцевальный клуб «Оливия»

Готовый сайт клуба в Великих Луках: группы и абонементы, расписание,
фотографии, руководители Артём и Алиса, контакты и документы.
Экспорт от **17 октября 2026 года**, включает последние изменения раздела тренеров.

Сайт написан на HTML, CSS и JavaScript. Содержимое папки `site/` одновременно
является исходниками и готовыми файлами для размещения. Сборка и установка
дополнительных пакетов не требуются.

## Структура

- `site/index.html` — главная страница, тексты, раздел тренеров и контакты.
- `site/assets/` — фотографии, логотип, ветки, шрифты, стили и JavaScript.
- `site/assets/content.js` — расписание, названия групп, цены и контакты.
- `site/assets/brand.css` — фирменные цвета и оформление.
- `site/assets/coaches.css` — оформление руководителей и их достижений.
- `site/legal/` — документы и реквизиты для посетителей сайта.
- `docs/UPLOAD_TO_GITHUB.md` — загрузка в свой репозиторий GitHub.
- `docs/HOSTING.md` — размещение сайта на отдельном хостинге.
- `scripts/package_site.py` — создание ZIP для загрузки на хостинг.
- `FONT-LICENSES.txt` — лицензии шрифтов; сохраняйте при передаче исходников.

## Быстрый просмотр на компьютере

Если установлен Python, запустите из папки репозитория:

```sh
python3 -m http.server 8080 --bind 127.0.0.1 --directory site
```

В Windows обычно используется команда:

```powershell
py -m http.server 8080 --bind 127.0.0.1 --directory site
```

Затем откройте <http://127.0.0.1:8080>. Остановка — Ctrl+C.
Локальный сервер нужен для корректной работы JavaScript-модулей.
Статические адреса `/assets/` и `/legal/` рассчитаны на размещение сайта
в корне домена.

## Загрузка на GitHub и публикация

Начните с `docs/UPLOAD_TO_GITHUB.md`. Для хранения исходников удобно создать
приватный репозиторий `olivia-website`.

После загрузки код будет храниться в вашем аккаунте GitHub. Публикация сайта
на домене выполняется отдельно: на Beget, другом выбранном хостинге или своём
сервере. Текущий сайт и DNS экспортом не переключаются. Автоматическая
синхронизация с исходным сайтом или новым хостингом пока не настроена.

GitHub Pages имеет ограничения на размещение онлайн-бизнеса и сайтов,
ориентированных на коммерческие операции. Этот комплект подготовлен
для хранения кода в GitHub и размещения сайта на обычном хостинге.
Правила: <https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits>.

## Подготовка архива для хостинга после изменений

```sh
python3 scripts/package_site.py
```

В Windows: `py scripts/package_site.py`.
Результат: `build/olivia-site.zip`. Архив содержит `index.html`, `assets/`
и `legal/` прямо в корне. Его можно распаковать в папку сайта на хостинге.

## Запись на занятия

Форма составляет черновик в браузере. Посетитель самостоятельно копирует
его и отправляет в группу ВКонтакте. Серверная отправка заявок, база данных
и аналитические счётчики в код сайта не добавлены.

## Содержимое экспортной копии

Канонические адреса и область действия политики указывают на `https://oliviavl.ru`.
В политике хостинг описан обобщённо: при выборе сервера нужно уточнить
фактического поставщика, его условия и размещение данных.
Контактный email сохранён по данным владельца: `dance@olivevl.ru`.
Почтовый домен отличается от домена сайта; это не автоматическая замена адреса.

Фотографии предоставлены владельцем клуба. В комплекте только используемые
на сайте оптимизированные копии. Лицензии шрифтов перечислены отдельно;
самостоятельная открытая лицензия на бренд, тексты и фотографии не назначена.
