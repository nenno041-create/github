# Размещение сайта на хостинге

В папке `site/` находится весь готовый сайт. Для работы посетителей не нужны
Node.js, Python, PHP-приложение или база данных. Нужен веб-сервер,
обслуживающий статические файлы, и HTTPS для домена.

## Beget или другой обычный хостинг

1. Подключите хостинг и создайте сайт для `oliviavl.ru`.
2. Посмотрите в панели, какая папка назначена корнем этого сайта.
   Обычно это `public_html`, но используйте фактический путь из панели.
3. Распакуйте `hosting/olivia-site.zip` из внешнего комплекта в эту папку.
   Можно вместо этого перенести всё содержимое `site/` из репозитория.
4. В корне сайта должны лежать `index.html`, папки `assets` и `legal`.
   Вложенной папки `site` или второй папки `public_html` быть не должно.
   Обработайте стартовую страницу хостинга так, чтобы открывался ваш `index.html`.
5. Проверьте копию по техническому адресу хостинга, если он предоставлен:
   главную страницу, фотографии, раздел тренеров, расписание и документы.
6. Получите точный IP нового хостинга из панели. После подготовки файлов
   переключите A-записи домена на этот IP. Для `www`, если он используется,
   настройте отдельную привязку к тому же сайту.
7. Выпустите SSL-сертификат и настройте перенаправление на HTTPS
   в порядке, предусмотренном хостингом. Затем проверьте домен
   с телефона и компьютера, включая обычное подключение без VPN.

MX-записи отвечают за почту; перенос веб-сайта сам по себе не требует их удаления.
В комплекте нет готового IP для DNS: он зависит от выбранного сервера.

Файл `.htaccess` задаёт стартовую HTML-страницу и отключает список файлов
при поддержке Apache. Для Nginx или Caddy используются настройки выбранного
веб-сервера; этот файл на них не рассчитывается как средство защиты.

## Свой сервер

Назначьте папку `site/` корневой папкой домена в веб-сервере и настройте HTTPS.
Сайт использует абсолютные пути `/assets/` и `/legal/`, поэтому размещается
в корне домена. Архив совместим со статической раздачей через Nginx,
Apache или Caddy; конфигурация зависит от выбранной системы.
Локальный сервер Python из README предназначен для проверки на компьютере.

## Последующие обновления

Измените файлы в репозитории. Запустите `scripts/package_site.py` и загрузите
обновлённый ZIP на хостинг. На первом этапе это ручная публикация;
затем можно отдельно настроить доставку файлов из GitHub на выбранный сервер.
