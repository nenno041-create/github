# Как загрузить сайт на GitHub

1. Распакуйте внешний архив `olivia-github.zip`.
2. Откройте папку `olivia/github/`. Именно её содержимое загружается
   в корень нового репозитория. `README.md` должен оказаться в его корне,
   а главная страница — по пути `site/index.html`.
3. На <https://github.com/new> создайте репозиторий `olivia-website`.
   Выберите `Private`. Для удобного первого экрана можно включить создание README.
4. В репозитории выберите `Add file` → `Upload files`.
   Для пустого репозитория также доступна ссылка загрузки существующего файла.
5. На компьютере перетащите содержимое `github/` в окно загрузки,
   сохраняя папки `site`, `docs` и `scripts`.
   Если README уже создан, загружаемый README заменит его.
6. Введите описание, например `Добавлен сайт Оливии`, и сохраните изменения
   через предложенную GitHub кнопку Commit/Propose changes.
7. Убедитесь, что видны `site/index.html`, `site/assets/`, `site/legal/`
   и главный README. Инструкция `docs/HOSTING.md` объясняет следующий шаг.

Удобнее загружать папки с компьютера: мобильный браузер может показывать
выбор отдельных файлов. В комплекте менее 100 файлов для GitHub;
каждый файл значительно меньше лимита веб-загрузки 25 MiB.
Если загружать только ZIP как один файл, GitHub сохранит этот ZIP;
для обычного редактирования сайта загружайте распакованные файлы.

Загрузка в репозиторий сохраняет код и историю изменений. Для доступности
сайта на домене нужно отдельно разместить содержимое `site/` на хостинге.

Официальная инструкция:
<https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository>.
